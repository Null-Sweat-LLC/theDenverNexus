### [Test2Doc Playwright](packages/test2doc-playwright)
A [Playwright](https://playwright.dev/) reporter that turns your test files into Docusaurus-compatible markdown, so your technical documentation stays in sync with your code.

### [Test2Doc Maestro](packages/test2doc-maestro)
A CLI that generates Docusaurus docs from [Maestro](https://maestro.dev) flow runs. Maestro has no reporter API, so it reads the artifacts of a finished run and writes the docs for your Android, iOS, or web flows.

### [Playwright Utils](packages/playwright-utils)
Playwright helpers for testing server-rendered React apps, such as `clickUntil`, which retries a click until the handler has actually hydrated, so tests stop flaking on buttons that are clickable before they work.

### [Playwright Passkey Gen](packages/playwright-passkey-gen)
A CLI and library that generates test passkey credentials for WebAuthn testing. It uses only `node:crypto` (no browser needed) and produces credentials ready for Playwright's `browserContext.credentials` API, plus the COSE public key to seed your database.

## Root commands
```
pnpm docker:ci:test
```
Run tests like in Github Actions (not exactly the same though) to see why our CI is failing or to update tests.

```
pnpm docker:ci:shell
```
Log into a container that should be similar to that of Github Actions to help debug the CI.
