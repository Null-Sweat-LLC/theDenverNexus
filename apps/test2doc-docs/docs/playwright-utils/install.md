# Install

`@test2doc/playwright-utils` is a set of Playwright helpers for testing server-rendered React apps.

```sh
pnpm add -D @test2doc/playwright-utils
```

It requires `@playwright/test` 1.40 or later and has no other dependencies.

The other pages in this section are generated by Test2Doc from the package's own tests, so every example on them runs in CI.
