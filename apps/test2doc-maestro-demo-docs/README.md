# test2doc-maestro-demo-docs

Docusaurus site for the docs that `@test2doc/maestro` generates from the
[test2doc-maestro-demo](../test2doc-maestro-demo) app's Maestro flows.

```bash
# from apps/test2doc-maestro-demo, with the emulator and Metro running
pnpm e2e:docs
# then here
pnpm generate
pnpm start
```

`docs/test2doc-*` and the screenshots next to them are generated. Do not edit
them by hand.
