# Manage your todo list

## Add a todo item

Open the app. Your todo list starts out empty.

<Tabs groupId="platform">
  <TabItem value="android" label="Android">

![Add a todo item](./test2doc-cd33ebe8177c.png)

  </TabItem>
  <TabItem value="ios" label="iOS">

![Add a todo item](./test2doc-23888c1a9292.png)

  </TabItem>
  <TabItem value="web" label="Web">

![Add a todo item](./test2doc-919f707421c2.png)

  </TabItem>
</Tabs>

1. Tap the text field at the top of the screen.

2. Type what you need to do.

3. Press **Enter** on the keyboard.

Your new item appears in the list with an empty checkbox (☐).

<Tabs groupId="platform">
  <TabItem value="android" label="Android">

![Add a todo item](./test2doc-db8bb32b83a4.png)

  </TabItem>
  <TabItem value="ios" label="iOS">

![Add a todo item](./test2doc-632877cf9d11.png)

  </TabItem>
  <TabItem value="web" label="Web">

![Add a todo item](./test2doc-ce29029e47df.png)

  </TabItem>
</Tabs>

:::tip
Repeat these steps to add as many items as you like.
:::

## Delete a todo item

:::warning
Deleting a todo item is permanent. There is no undo.
:::

<Tabs groupId="platform">
  <TabItem value="android" label="Android">

![Delete a todo item](./test2doc-6cb139267c0d.png)

  </TabItem>
  <TabItem value="ios" label="iOS">

![Delete a todo item](./test2doc-a2786d7a6b84.png)

  </TabItem>
  <TabItem value="web" label="Web">

![Delete a todo item](./test2doc-a44c44ac0f8d.png)

  </TabItem>
</Tabs>

1. Tap **Delete** next to the item you want to remove.

The item is removed and the rest of your list stays as it was.
